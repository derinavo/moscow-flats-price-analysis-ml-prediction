# Прогноз стоимости недвижимости в Москве

Проект по анализу рынка недвижимости Москвы и прогнозированию стоимости квартир с помощью методов машинного обучения.

В проекте выполнены:
- исследовательский анализ данных (EDA);
- подготовка и генерация признаков;
- сравнение нескольких моделей регрессии;
- подбор гиперпараметров;
- кросс-валидация;
- эксперимент с `log(price)`;
- анализ важности признаков и ошибок модели;
- Streamlit-приложение для интерактивного прогноза стоимости квартиры.

## Используемые признаки

В модели используются характеристики квартиры и её расположения, в том числе:

- общая площадь;
- количество комнат;
- этаж;
- признак первого этажа;
- район;
- расстояние до центра Москвы.

Расстояние до центра рассчитывается относительно Красной площади.

## Модели

В ноутбуке сравниваются:

- Linear Regression;
- Random Forest;
- Gradient Boosting;
Модели после автоподбора гиперпараметров:
- Tuned Random Forest;
- Tuned Gradient Boosting;
Лучшая модель с поправкой на выбросы из-за единичных дорогих квартир:
- Tuned Random Forest log.

Качество моделей оценивается с помощью:

- MAE;
- RMSE;
- R2;
- кросс-валидации.

Для финальной модели также проводится анализ важности признаков и анализ объектов с наибольшими ошибками прогноза.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

### 2. Создать виртуальное окружение

Windows:

```bash
py -m venv .venv
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
py -m pip install -r requirements.txt
```

### 4. Скачать датасет

Скачайте `realty_data.csv` по ссылке выше и поместите файл в корневую папку проекта.

## Запуск приложения

В терминале перейдите в папку проекта:

```bash
cd C:\Users\...\путь_к_проекту
```

Запустите Streamlit:

```bash
py -m streamlit run Prognoz_app.py
```

После запуска Streamlit откроет приложение в браузере.

## Возможности приложения

Приложение содержит две вкладки:

1. **Обзор рынка**
   - количество объектов;
   - медианная стоимость;
   - медианная цена за м²;
   - медианная площадь;
   - фильтрация по районам и количеству комнат;
   - сравнение районов;
   - распределение цен.

2. **Прогноз цены**
   - ввод площади;
   - количества комнат;
   - этажа;
   - выбор района или расстояния до Красной площади;
   - автоматическая подготовка признаков;
   - прогноз полной стоимости квартиры;
   - прогноз цены за м².
